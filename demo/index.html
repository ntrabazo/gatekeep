When this page loaded, it ran all 150 prompts from the project's two red-team test sets through the same engine you are about to use. The first set has 50 secrets and personal-data cases, including traps that should not trip it, like Git hashes and invalid card numbers. The second has 100 prompt-injection cases, including innocent sentences that use words like "ignore" and "developer mode". The browser engine is also checked against the original Python engine, finding by finding, on every commit.

Stop sensitive data before it reaches the AI.

Gatekeep sits between a team and the Claude API and checks every prompt on the way out. Secrets get blocked, personal data gets redacted, and hijack attempts get stopped. Every decision is logged without ever storing the prompt itself.
