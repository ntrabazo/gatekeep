When this page loaded, it ran all 209 prompts from the project's two red-team test sets through the same engine you are about to use. The second has 159 prompt-injection cases in nine languages, including innocent sentences built to trip it, like "don't ignore the instructions on the label". The browser engine runs the exact pattern table the Python engine exports, and is checked against it, finding by finding, on every commit.
